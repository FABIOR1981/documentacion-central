# documentacion-central

Documentación de los proyectos de [FABIOR1981](https://github.com/FABIOR1981). Hay un directorio por proyecto, con el mismo nombre que su repositorio, y adentro una carpeta `documentacion/`:

```
<nombre-del-repo>/documentacion/
```

En cada proyecto, la carpeta `documentacion/` tiene solo un `LEEME.md` que remite acá. La documentación también se puede consultar desde la bitácora de proyectos.

## Agregar o actualizar la documentación de un proyecto

1. Usá el directorio `<nombre-del-repo>/documentacion/`. Si no existe, crealo con el nombre exacto del repositorio.
2. Dentro de esa carpeta, los links e imágenes relativos (por ejemplo `img/captura.png`) funcionan igual que antes.
3. Este repositorio es **público**: no subas documentación de repositorios privados, ni datos personales o claves.
